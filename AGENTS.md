# Mind Layer standalone edition

- Keep this runnable without Sonzai accounts, license servers, metering or paid
  Sonzai services. Optional model-provider usage must remain explicit.
- This is a scoped edition, not hosted-platform parity. Read `docs/capabilities.json`
  and `docs/hosted-scope.json` before making capability claims.
- Every supported docs claim needs passing named tests. Run `make verify`.
- `docs/capabilities.md` and `docs/benchmarks.md` are generated by
  `scripts/build_docs.py`; edit their JSON inputs or generator, not only the output.
- Benchmark results must name the dataset, mode, model and measurement conditions.
  Do not describe the synthetic diagnostic as LoCoMo, LongMemEval or answer accuracy.
- Use authored synthetic fixtures. Never import source Git history, customer data,
  environment files, private contact details, or production deployment configuration.
- Run `python3 scripts/check_release.py` after building docs. Keep findings private
  in Git metadata. Automated scanning is not proof that all PII has been excluded.
- The service token is an owner credential for all scopes. Do not describe scope
  IDs as end-user authentication. Deletion is logical, not secure erasure.
- Preserve Apache-2.0 and upstream license notices. Do not publish or deploy unless
  requested by the user; local preparation does not imply a completed release.
